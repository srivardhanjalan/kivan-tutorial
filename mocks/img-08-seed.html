Seed

A catalog the runtime can't write

Seeding writes both tables from your own credentials. The running server can only read them.

You
developer creds
DynamoDB
storefronts + products
App Runner
the instance role
The instance role gets Scan on storefronts and Query on products, and no write action on either, so nothing the server runs can overwrite a store. The catalog changes only when you re-run the seed.
